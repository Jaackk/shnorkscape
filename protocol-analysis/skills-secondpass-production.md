# Production skills: second-pass review for revision 950

This pass improves the existing native skill loops, using the 910 content as the policy reference and the paired 950 cache as the identity/recipe authority. It does not claim to port every training method, modern production interface, boost or unlock.

## Shared changes

Recipe selections now explain their skill level, base XP, exact input quantities and current backpack amounts, required tools and output batch size in chat. The native quantity dialogue retains Make 1 / 5 / 10 / all; Make-all displays the material-based batch limit. Selection closes before starting an action, stale dialogue responses remain rejected, and requested quantities are bounded by available inputs. The displayed bound is not a reservation: space, tools (including thread consumption), movement, station identity and controller permission are checked again at each completion.

Missing inputs now identify the exact shortage instead of conflating it with a full inventory. Output capacity failures have a separate message. Shared production, leather Crafting and anvil Smithing report material/tool loss mid-batch instead of silently stopping. ID-only recipes explicitly refuse charged or customised input instances before container validation. The previous container invariant already rejected unsupported personalised inventory state; this change supplies useful feedback rather than claiming to repair a reachable duplication exploit.

The production scheduling, inventory transaction and Skills XP owners remain the original ActionManager and native container boundary. There are no parallel timers or debug XP grants. Native 950 dialogue 1188 remains the menu; this is not the full RuneScape Make-X catalogue or slider.

## Practical checks

- Stringing: carry gold amulet (unstrung) **1673** and ball of wool **1759**, use either on the other, select the product then quantity. The paired cache requires **Crafting 8**. Output **1692**, one of each input per amulet, **4 base XP**. Fourteen of each fills a backpack and still permits fourteen replacements. The other newly supported outputs are **1694, 1696, 1698, 1700, 1702, 6581 and 1716**, with their own cache levels. Sapphire requires 24; onyx requires 90.
- Prayer: the natural Varrock church altar **24343** is at **3253,3486,0**. Right-click **Offer** with unnoted bones **526** or impious ashes **20264**; choose one type and a quantity. Using the offering item on the altar starts that type automatically. **Pray at** restores Prayer points. Additional verified scene locations are palace altar **409** at **3208,3494,1** and monastery altar **2640** at **3051,3498,1**.
- Cooking: try a raw apple pie **2317** on an open fire, then on a range; only the range should start baking. Fish and ordinary meat still work at either.
- Inspect any shared recipe while missing an ingredient or tool; the message should name what is needed. Cancelling or walking away before completion must leave remaining inputs untouched.

The natural altar IDs and coordinates above were read from the paired 950 scene. Automated route fixtures place those same pinned objects temporarily on clear test tiles; they do not modify a running world or account save. Client pixels, animation presentation and physical keyboard/mouse interaction still require an in-game check.
