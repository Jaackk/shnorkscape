# Standalone update — 12 September 2026

Updated from the current 950RevTest project. This includes subsequent skill refinements, persistent skill progress, toolbelt, native production interfaces and drag fixes, equipment movement fixes, lobby cleanup, expanded ribbon/navigation, Hero/Loadout, quest browsing, and native boss/activity information pages. All updated gameplay source, resources and tests are included.

The standalone keeps its bundled runtimes, portable launch/build scripts, local-only service configuration, fast JS5 transfer and automatic client-cache preparation. Its original OpenNXT base JAR is retained for those optimizations; current lobby/ribbon overrides are rebuilt from the synchronized source. The engine is rebuilt from the standalone source so removed legacy service credentials are not reintroduced.

Existing cache, client state and characters are preserved. The backup archive beside this folder contains the previous changed source, engine, compiled overrides, manifest and character files. The main project's running server and client are unaffected. Stop that copy before launching this one because they use the same local ports.

## Known issues carried over

- The minimap exit button opens the correct Options UI, but it can disappear quickly. This remains unresolved. Stop.cmd remains available to stop this standalone copy.
- Beasts now populates boss names, descriptions, artwork and rewards. Some combat/stat values are still placeholders. Encounter participation and kill records are not implemented by the information browser.
- Native navigation does not implement every feature inside cosmetics, social/grouping, abilities, achievements or quests. See docs/history/RIBBON-MENUS-950.md for scope.
- This update changes the folder contents. The pre-existing 950OpenSource.7z archive is an older snapshot and was not rebuilt. Create a fresh archive from the updated folder, excluding that old archive and any data you do not intend to share.

Normal launch remains Play.cmd. Cache requirements are unchanged. Optional historical research tools may require Python; normal play and the portable build do not.
