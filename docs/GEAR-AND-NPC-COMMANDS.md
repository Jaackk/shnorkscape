# Gear, searches and test NPCs

Use Jaxa. New tools require the existing local native developer connection plus administrator rights or the explicit developer account grant. NPC spawning now also requires that account permission.

| Command | Result |
| --- | --- |
| `;;meleegear` | Torva, Chaotic rapier, Fire cape, Fury, Barrows gloves, Dragon boots, Berserker ring |
| `;;magegear` | Virtus, Chaotic staff, Fire cape, Fury, Barrows gloves, Infinity boots, Berserker ring |
| `;;rangegear` | Pernix, Chaotic crossbow, Fire cape, Fury, Barrows gloves, Dragon boots, Berserker ring, 10,000 Dragon bolts (e) |
| `;;weapons` | Noxious scythe, staff and longbow; main/off-hand Drygore rapiers |
| `;;gear melee` / `mage` / `range` / `weapons` | Alternative kit syntax |
| `;;search torva` | Find matching item IDs/names |
| `;;search torva 2` | Second page; ten results per page |
| `;;findnpc goblin` | Find matching NPC definition IDs |
| `;;findnpc goblin 2` | Second page of NPC matches |
| `;;npc 12353` | Spawn one test NPC at your current tile |
| `;;npc 12353 5` | Spawn five, with a limit of 50 per command and 128 diagnostics in the world |
| `;;npcs` | List up to ten of your test NPCs within 48 tiles on your plane, including their live indexes |
| `;;removenpc 42` | Remove your test NPC with live index 42; this is not its definition ID |
| `;;clearnpcs 10` | Remove your test NPCs within ten tiles on your plane |
| `;;clearnpcs` | Remove all your currently registered test NPCs |
| `;;gearhelp` | In-game help |

Item search aliases: `find`, `si`, `itemid`, `finditem`. NPC search alias: `snpc`. Removal alias: `delnpc`. Existing `;;item <id> [amount]` supplies individual items.

Kits match the named armour/Chaotic loadouts in your Matrix custom command block, with item identities checked against the actual950 names. Kits go into the backpack as one staged transaction; insufficient space grants nothing. Existing equipment is preserved. Equip items normally and use `;;max` when you explicitly want the required levels. The weapon kit supplies items, not special-attack mechanics, spells or abilities. Magic supplies/spell selection remain separate.

Search catalogs were generated by `Export-950CacheNames.ps1` from this project's paired cache with zero decode errors (63,414 item definitions and 32,762 NPC definitions). Generated resources are `native950/search-items.tsv` and `search-npcs.tsv`; regenerate them when deliberately changing cache versions. Search includes named variants and marks noted/lent/bound items. A name match does not guarantee the NPC has supported combat or every item effect is implemented.

Spawns use the native diagnostic factory and existing combat admission. A refusal explains unsupported NPCs. Counted spawns retain the existing exact-player-tile placement, so several can overlap. NPC removal only targets diagnostics created by your username during this server run; normal world NPCs, other players' spawns, spawn files and boss scripts are not removed. Removal unregisters native combat and cancels that fighter's pending respawn. These are temporary development spawns, not persistent world-content edits.

Reference sources: the Matrix custom block containing `meleegear`, `magegear`, `rangegear`, `search/find/si/itemid`, `findnpc/snpc`, `npc` and `clearnpcs`; Darkan's development NPC command examples. Existing `god`, `coords` and item tools were retained. The old equipment-reset implementation and global cleanup list were not copied.
