On the FRIEND'S Windows PC only:
1. Extract the ENTIRE ZIP into a writable local folder, for example
   Desktop\SHNORKSCAPE LAN. Paths containing spaces are supported.
   Do not overwrite an existing server/client installation.
2. Double-click Play SHNORKSCAPE.cmd.
3. Log in with the separate guest username/password Jack gives you privately.

Jack starts normal Play.cmd on his PC first. Both PCs must be on the home LAN.
Initial cache downloading can take time. No PowerShell, admin rights, Java,
Git or developer tools are needed. Requires current Windows 10/11 and a Vulkan
graphics driver. No separate non-system DLL is bundled or required.
If Jack's IP changes, the LAN_HOST line near the top of Play SHNORKSCAPE.cmd
is the only guest setting to update. Normally no editing is necessary.
Client cache/settings stay in client-state beside the launcher. Launch through
the CMD file so its working directory is set correctly.
No router port forwarding is needed. Guest/isolated Wi-Fi may block LAN access.

If Windows or antivirus blocks this package, stop and tell Jack. Do not disable
security, add exclusions or restore quarantined files. Read any launcher error.
