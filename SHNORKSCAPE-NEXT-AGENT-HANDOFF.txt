3. P0 INPUT PATH: EXACT CURRENT OWNERS
Inbound exact-950 IF_BUTTON options 1..10 have opcodes
18,122,89,100,81,126,49,66,31,59 (in option order). Native950Actions.java
decodes their 9-byte payload to InterfaceAction; DRAG opcode 12 decodes to
DragAction. No 947 opcode substitution. Native950GameTransport.java frames,
decodes and queues actions, then Native950Session.tickInput drains them in world
phase 1a. Session routes through Native950Interactions.handle(action), which
routes interface/drag to Native950ActionBar.button/drag and other UI owners.
Native950Session.tickMove runs manager/entity/movement phases; Native950World
owns shared combat, session roster and tick scheduler. Check this entire chain
with bounded Bug Test events at the first failed keypress, not only ability().
The transport can evict queued chat to admit actions; a queue full of non-chat
is a different failure. Do not assume a keypress necessarily became IF_BUTTON.

Native950ActionBar.java owns 4 saved bars, 14 slots each. Persistent settings:
actionBar.<bar>.<pair> (7 packed pairs/bar), actionBar.active,
actionBar.revolution. It migrates the original bar-one keys. Packed native
shortcut = (type << 17) | (enumKey << 4); varbits 1747 type (varp739 bits17..23)
and 1748 key (bits4..16). Type -> enum:
1 melee 10147; 3 defence 6736; 4 constitution 6737; 5 ranged 6738;
6 magic 6740; 7 necromancy 16973. Do not repack with old four-bit type.
Main bar interface1430 slot children64..238 in groups of13; Powers mirror1436
uses children19/20 +13*n. Source books have their own mounts and masks.
Book source validation is in bookType; struct(packed) resolves enum key to
cache structure. ActionBar.button expects option1 for ability activation;
validates mounted child 1430 OR workspace wrapper1477 (corrected in 9cf04a1),
player active/unlocked/not dead, slot binding, then combat.ability(structure).
Spell selection on 1461:1 option2 is separate. Native preset selector is
1430:261 (also accepts254); action bar root is1477.
